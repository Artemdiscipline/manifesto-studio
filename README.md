# Manifesto — одностраничный сайт

Статика без сборки: `index.html` (CSS и JS внутри) + `assets/`. Открывается с любого хостинга, корень сайта = эта папка.

```
index.html        страница
robots.txt        index, ссылка на sitemap
sitemap.xml
assets/
  favicon.svg, apple-touch-icon.png
  og.jpg          1200×630 для соцсетей
  fonts/          Unbounded + Onest, woff2 (cyrillic, latin, latin-ext)
  works/          work-01…13 .webp + .jpg, 640×800 (4:5)
  img/            atmosphere.webp/.jpg — зал студии
```

## Адрес сайта

Сейчас сайт опубликован на GitHub Pages: https://artemdiscipline.github.io/manifesto-studio/ (репозиторий `Artemdiscipline/manifesto-studio`, Pages из `main`, корень).

При переезде на свой домен замените `https://artemdiscipline.github.io/manifesto-studio/` на новый адрес (поиск по `artemdiscipline.github.io`):

- `index.html` — `<link rel="canonical">`, `og:url`, `og:image`, `twitter:image`, в JSON-LD: `@id`, `url`, `image`, `logo`;
- `robots.txt` — строка `Sitemap:`;
- `sitemap.xml` — `<loc>`.

Поисковики читают `robots.txt` только из корня домена. На github.io-подпапке он не учитывается, но и не мешает: заработает после переезда на свой домен.

## Подтвердить у студии

1. **Часы работы.** В 2ГИС указано 10:00–21:00, в MastersApp — 10:00–22:00. На сайте и в JSON-LD стоит 21:00.
2. **Комбо за 4 400 ₽** (реклама в 2ГИС). По текущему прайсу Sculpt 2 000 ₽ + педикюр Maxi с покрытием 2 400 ₽ = те же 4 400 ₽, то есть скидки нет. Блок закомментирован в разделе цен. Вернуть его, если студия подтвердит состав и выгоду.
3. **«В четыре руки».** Это упоминается в одном отзыве, но такой услуги нет в прайсе MastersApp. На сайте в FAQ написано мягко: «позвоните — подскажем, есть ли такое окошко».
4. **Наращивание «до 3».** В MastersApp описание звучит как «наращивание до 3». Скорее всего, это длина. На сайте этой детали нет, в коде оставлен комментарий.
5. **Мужской педикюр.** Его нет в прайсе MastersApp, но он есть в рубриках 2ГИС. Цена на сайте не указана.
6. **Японский маникюр** (от 1 300 ₽) есть в MastersApp, но описания у него нет. Можно дописать одну строку.
7. **Фото.** Все фото взяты из Telegram-канала самой студии. Перед публикацией нужно получить согласие, особенно на фото зала: на нём видны мастер и гости, хотя и не в фокусе.
8. **Мастера.** Блок «Мастера» закомментирован. Имена (Анастасия, Дарья, Ксения, Елена, Вероника) и фото ставить только с согласия.
9. **Второй телефон во ВКонтакте:** +7 995 272-14-04. На сайте указан основной номер +7 995 570-57-57 из 2ГИС и MastersApp. Узнать, действует ли второй номер. В ВК также старая цена Standart — 1 600 ₽.

## Не удалось проверить

- **Яндекс Карты.** Из рабочей среды карточка не открылась: поиск отдаёт «Ничего не найдено», встроенный браузер на yandex.ru не пускает. Ссылка «Яндекс Карты» на сайте построена по координатам, её стоит заменить на ссылку карточки организации. Через WebSearch всплывает «4,9 и 79 отзывов» без ссылки на источник, поэтому эти цифры на сайт не пошли.

## Техника

- Шрифты свои, без Google Fonts; кириллица подгружается через preload. Всего 2 семейства.
- Карта OpenStreetMap грузится только по кнопке «Показать карту», чтобы не тормозить страницу и не перехватывать прокрутку на телефоне.
- Анимация одна: в hero золотой линией прорисовываются пять пальцев с маникюром, центральный ноготь «покрыт» золотом. При `prefers-reduced-motion` они показываются сразу, без анимации.
- Онлайн-записи и форм на сайте нет: все кнопки «Записаться» ведут на `https://mst.link/manifesto/price` в новой вкладке.
- В JSON-LD `BeautySalon` нарочно нет `aggregateRating`: это была бы самооценка, которую Google не засчитывает.
